# MusiX v1.0.2

## Improvements

- Added a single animated background that is painted behind every screen for a more consistent look.
- In-app updates can now be paused and resumed, with progress shown in the UI.
- Translated the network and error copy into all 22 shipped languages.
- Library collection filters now lay out as a row instead of stacking into a column.

## Fixed

- Losing the network connection now shows a clear, translated message instead of failing silently.
- The accent colour now reaches `ThemeData`, and system theme mode no longer disagrees with itself.
- The update check no longer fails on an otherwise successful response.
- The license page no longer prints its own translation key.
- A translated error snackbar could overflow its own bar.
- Repaired the APK resume test for Dio 5.

## Notes

- Built with Flutter. All tests and analysis pass.
