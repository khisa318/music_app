# MusiX v1.0.0

The first public release of MusiX — a free, open-source, ad-free music player for Android.

## Highlights

- Stream from YouTube Music and JioSaavn with a clean, modern player.
- Home with shelves for covers and remixes, trending, and your play history.
- Search across songs, artists, albums, playlists and videos.
- Library with per-collection tabs and chips; playlists, albums and artists.
- Playlists: create your own and import from YouTube.
- Downloads: save songs and playlists for offline playback.
- Lyrics, an equalizer, and a full Now Playing experience.
- Profile and Settings restyled in the "About MusiX" design.
- In-app updates that read from GitHub Releases.
- 22 shipped languages.

## Notes

- Built with Flutter. All tests and analysis pass.
