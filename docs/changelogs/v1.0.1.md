# MusiX v1.0.1

## Fixed

- Release signing: the signing config was assigning properties to themselves, and the keystore secrets were never passed to any build step. Both are corrected so release APKs are signed with the project key.
- CI: the release tag filter was written as a regex rather than a glob, so no release workflow ever ran. It is now a glob that matches `v1.0.1` and the tags the release workflow watches for.

## Notes

- Maintenance release focused on the release and signing pipeline. No user-facing changes.
